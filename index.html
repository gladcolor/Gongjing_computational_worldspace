An idea you can explore

A shared space for understanding how systems change.

Gongjing (共境) is a proposed way for people and scientific AI tools to work with the same computer model of a system.

That shared model is called a computational worldspace. It records the parts of a system, how they affect one another, the rules that limit change, and what can be observed. These early demonstrations make that idea visible.

What does this show?

A proof of concept is an early working example used to test an idea. Here, you can change an input or a rule and see how the system responds.

The influence cellular automata and river simulation are proofs of concept for Gongjing. A cellular automaton is a grid whose cells change according to rules. The river example uses the Gongjing software core to start the model, advance it, read results, and make changes.

The longer-term aim is a shared way to explore, compare, and explain scientific models. These pages demonstrate model behavior and software structure; they do not yet demonstrate an AI system carrying out independent research.

Read the results in context.

These are simplified, synthetic worlds. The cell model's influence is an abstract quantity. The river models use relative values and simplified flow rules. They have not been calibrated to a real river or ecosystem.

Use them to explore feedback and pattern formation. They are not tools for forecasting floods, making engineering decisions, or predicting real plant growth.
