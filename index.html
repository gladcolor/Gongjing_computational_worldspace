A scientific architecture you can inspect

A shared space for understanding how systems change.

Gongjing (共境) is an experimental framework for people and scientific AI tools to work with the same computational representation of a system.

A computational worldspace keeps entities, states, influences, constraints, interventions and observations connected. The live case studies below show how a shared interface can organize different kinds of evolving models.

What does Gongjing add?

A domain model calculates changes. Gongjing adds a shared structure for describing the modeled world, reading its state, applying permitted interventions, comparing outcomes and preserving the experiment record.

The watershed case shows this separation directly: the watershed adapter contains the domain rules, while the Gongjing core provides common commands for initialization, stepping, observation, description, intervention and cross-scale pattern summaries.

The longer-term aim is to let people and scientific AI tools explore, compare and explain models through the same interface. These pages demonstrate model behavior and software structure; they do not yet demonstrate an AI system carrying out independent research.

Read the results in context.

These are simplified, synthetic worlds. The cell model's influence is an abstract quantity. The river models use relative values and simplified flow rules. They have not been calibrated to a real river or ecosystem.

Use them to explore feedback and pattern formation. They are not tools for forecasting floods, making engineering decisions, or predicting real plant growth.
